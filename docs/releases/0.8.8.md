# v0.8.8 — An export from the terminal

For people who work from a checkout of this repository: one command now makes an export with no extension installed. The extension itself, and the export it makes from the popup, are the same as in 0.8.7.

> [!NOTE]
> Unofficial. Not affiliated with, endorsed by or sponsored by Maccabi Healthcare Services.

## What's new

- **`npm run export` makes an export without the extension.** It opens a browser, signs in to Maccabi Online, runs the same collector the extension runs and writes the folder a ZIP would hold into `./maccabi-export-<today>/`, with the same `README.md`, `CLAUDE.md`, `AGENTS.md` and `export-errors.json` at its root. Thanks to [@Urigo](https://github.com/Urigo) for it ([#15](https://github.com/RoniRachmani/health-records-export-for-maccabi/pull/15)).
- **Test results by default, in about a minute.** `--all` takes every section the extension collects, `--steps visits,referrals` takes just those, and `--out` chooses where the folder goes.
- **It never orders the medical file.** Nothing on your account changes and Maccabi sends no SMS. With `--all` it takes the medical file already on the site, if there is one.
- **A rerun picks up where the folder is.** Run it again into the same folder and it rewrites only the JSON that changed and asks for no document it already has, as Resume does in the popup. A run that is stopped keeps what it collected.
- **A partial export says it is partial.** When only some sections were asked for, the export's `README.md` says the others were not collected in this run, so an AI assistant reading it does not take a missing folder to mean the site had nothing on record.

It needs Node, a checkout of the repository and your Maccabi credentials in 1Password, read through its CLI; [the README has the setup](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.8.8/README.md#an-export-from-the-terminal-without-the-extension). Signing in this way ends your other Maccabi sessions, and a wrong password is never resubmitted. The popup remains the way to export for everyone else.

The export's files and layout are the same as in 0.8.7, so an export paused on 0.8.7 resumes after the update.

## Install or update

You need Chrome 120 or newer.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/lmjcbhajlnbpldofejcglcdclceampjp)** and Chrome keeps it up to date — though store review can lag a day or two behind a release here.

To load this ZIP unpacked instead:

1. Download **health-records-export-for-maccabi-0.8.8.zip** from the assets below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder, the one with `manifest.json` in it. Keep that folder: Chrome loads the extension from it.

Updating from an earlier version: unzip over the old folder, or load the new one and remove the old entry, then press the reload arrow on `chrome://extensions`. An export in progress won't survive the swap — finish or stop it first.

Then [export your records](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.8.8/README.md#export-your-records), and [see what to ask your AI assistant](https://maccabi.ronirachmani.com/#ask). The code isn't minified, so you can read exactly what runs.

## Before you start

- **Maccabi will text you.** Each export from the popup orders a fresh copy of your medical file, which sends an SMS and replaces the previous file on the site. It's the only change the extension makes to your account.
- **Keep the Maccabi Online tab in front** until the export finishes. Chrome pauses hidden tabs.
- **If your session ends,** log in again and press **Resume**. The files collected so far are kept.

## Privacy

- Talks only to `online.maccabi4u.co.il`. No servers, no analytics, no remote code.
- Never sees your password or one-time codes. It uses the session you're already logged in with.
- Apart from ordering the medical file, it only reads. Every request it makes is listed in [docs/endpoints.json](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.8.8/docs/endpoints.json).
- **The extension sends your records nowhere, but an AI service you open them in can read them.** Check what it keeps, and for how long, before you give it your health information.
- **The ZIP isn't encrypted.** It holds your health information: keep it somewhere safe, and take care when you share it.
