# v0.8.13 — Today's medical file, ordered once

Two fixes to the medical file. One gives Maccabi more time to prepare it. The other makes sure an order is never sent twice. Nothing else about what is collected has changed.

> [!NOTE]
> Unofficial. Not affiliated with, endorsed by or sponsored by Maccabi Healthcare Services.

## What's changed

- **The export waits longer for today's medical file.** Maccabi keeps a single medical file on the site and puts the new one in the old one's place when it's ready. 0.8.12 waited only 2 minutes for that when an earlier day's file was still listed. On 26 October, Maccabi confirmed an order but hadn't swapped the file in by then, so the export came out with no medical file. Now it waits up to 15 minutes. If today's file still isn't there, the export keeps the earlier one, names it (and its dates, if it doesn't cover your whole history), and tells you to export again later that day. That export takes the ready file without ordering again.
- **An order is recorded the moment it goes out.** Chrome can stop the extension's background work at any time. If that happened after the order was sent but before Maccabi answered, the export forgot the order, ordered again when it resumed, and Maccabi could text you twice. The order is now saved as it's sent and again when Maccabi answers, so a resumed export never repeats it.

The export's files and layout are the same as in 0.8.12, so an export paused on 0.8.12 resumes after the update. The policies haven't changed.

## Install or update

You need Chrome 120 or newer.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/lmjcbhajlnbpldofejcglcdclceampjp)** and Chrome keeps it up to date, though store review can lag a day or two behind a release here.

To load this ZIP unpacked instead:

1. Download **health-records-export-for-maccabi-0.8.13.zip** from the assets below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder, the one with `manifest.json` in it. Keep that folder: Chrome loads the extension from it.

To update from an earlier version, unzip over the old folder, or load the new one and remove the old entry. Then press the reload arrow on `chrome://extensions`. An export in progress won't survive the swap: finish or stop it first.

Then [export your records](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.8.13/README.md#export-your-records), and [see what to ask your AI assistant](https://maccabi.ronirachmani.com/#ask). The code isn't minified, so you can read exactly what runs.

## Before you start

- **Maccabi will text you.** Each export from the popup orders a fresh copy of your medical file, which sends an SMS and replaces the previous file on the site. It's the only change the extension makes to your account.
- **Keep the Maccabi Online tab in front** until the export finishes. Chrome pauses hidden tabs.
- **If your session ends,** log in again and press **Resume**. The files collected so far are kept.

## Privacy

- Talks only to `online.maccabi4u.co.il`. No servers, no analytics, no remote code.
- The extension's links open its website or its GitHub issue tracker in your own browser, and only when you click them. The extension sends neither one anything. The website's home page counts visits without cookies; the extension itself counts nothing.
- Never sees your password or one-time codes. It uses the session you're already logged in with.
- Apart from ordering the medical file, it only reads. Every request it makes is listed in [docs/endpoints/endpoints.json](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.8.13/docs/endpoints/endpoints.json).
- **The extension sends your records nowhere, but an AI service you open them in can read them.** Check what it keeps, and for how long, before you give it your health information.
- **The ZIP isn't encrypted.** It holds your health information: keep it somewhere safe, and take care when you share it.
