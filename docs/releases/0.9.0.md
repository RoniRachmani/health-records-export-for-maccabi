# v0.9.0 — Maccabi Health Records Takeout

The extension has a new name: **Maccabi Health Records Takeout - Ready for AI**. It's the same extension, from the same developer, with the same Chrome Web Store listing. What it collects and how it works haven't changed.

> [!NOTE]
> Unofficial. Not affiliated with, endorsed by or sponsored by Maccabi Healthcare Services.

## What's changed

- **A new name.** The extension is now called Maccabi Health Records Takeout. The popup's heading reads *Health Records Takeout*, and Chrome's extensions page, the policies and the website use the new name. If you already have it installed, Chrome updates it in place, and you don't need to do anything.
- **A little less waiting between pages.** The export used to pause briefly after every page it opened. Now it pauses only on Maccabi's older pages, which need it.
- **More tests behind the export.** The way it retries a busy server, notices an ended session and runs the Maccabi Online tab is now covered by tests. The behaviour you see stays as it was.

The export's files and layout are the same as in 0.8.13, so an export paused on 0.8.13 resumes after the update. The [Privacy Policy](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.0/docs/privacy.md) and [Terms of Use](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.0/docs/terms.md) now use the new name, and nothing else in them has changed, so you won't be asked to accept them again.

## Install or update

You need Chrome 120 or newer.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/lmjcbhajlnbpldofejcglcdclceampjp)** and Chrome keeps it up to date, though store review can lag a day or two behind a release here.

To load this ZIP unpacked instead:

1. Download **health-records-export-for-maccabi-0.9.0.zip** from the assets below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder, the one with `manifest.json` in it. Keep that folder: Chrome loads the extension from it.

To update from an earlier version, unzip over the old folder, or load the new one and remove the old entry. Then press the reload arrow on `chrome://extensions`. An export in progress won't survive the swap: finish or stop it first.

Then [export your records](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.0/README.md#export-your-records), and [see what to ask your AI assistant](https://maccabi.ronirachmani.com/#ask). The code isn't minified, so you can read exactly what runs.

## Before you start

- **Maccabi will text you.** Each export from the popup orders a fresh copy of your medical file, which sends an SMS and replaces the previous file on the site. It's the only change the extension makes to your account.
- **Keep the Maccabi Online tab in front** until the export finishes. Chrome pauses hidden tabs.
- **If your session ends,** log in again and press **Resume**. The files collected so far are kept.

## Privacy

- Talks only to `online.maccabi4u.co.il`. No servers, no analytics, no remote code.
- The extension's links open its website or its GitHub issue tracker in your own browser, and only when you click them. The extension sends neither one anything. The website's home page counts visits without cookies; the extension itself counts nothing.
- Never sees your password or one-time codes. It uses the session you're already logged in with.
- Apart from ordering the medical file, it only reads. Every request it makes is listed in [docs/endpoints/endpoints.json](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.0/docs/endpoints/endpoints.json).
- **The extension sends your records nowhere, but an AI service you open them in can read them.** Check what it keeps, and for how long, before you give it your health information.
- **The ZIP isn't encrypted.** It holds your health information: keep it somewhere safe, and take care when you share it.
