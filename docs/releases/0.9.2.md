# v0.9.2 — One order, one text

Exporting again no longer orders your medical file again: one order a day, and a file ordered in the last few days is taken when it's ready. The extension waits longer for it, and says plainly when it isn't ready yet. The export's README now counts your own records, too.

> [!NOTE]
> Unofficial. Not affiliated with, endorsed by or sponsored by Maccabi Healthcare Services.

## What's changed

- **One order, one text.** A second export the same day, even after you cancelled the first, no longer orders your medical file again, so Maccabi doesn't text you twice. And when a file ordered in the last 3 days is ready but no export has collected it yet, the next export takes that one instead of ordering a new one.
- **A refused order is tried once more.** When Maccabi Online answers an order with "try again later", an export an hour or more after it, the same day, orders once more, and no export orders again that day. The popup and the notification say which applies.
- **A longer wait for the medical file, and Save now.** The extension now waits up to 30 minutes for Maccabi to prepare the file, up from 15. While it waits, **Save now** saves the ZIP without it.
- **When the file is late, it says so.** An export that finishes without the new medical file says so in the popup and the *Export ready* notification, and what to do: when Maccabi texts you, export again. That export takes a few minutes and won't order another.
- **Your records in numbers.** The export's README has a new section that counts what in *this* export its general cautions apply to: lab values given only as text or with no normal range, measurements whose units or range change over time, visit summaries that name no diagnosis, and how far back each folder goes. It measures the records' form, never whether they're right.
- **"Allergies and sensitivities".** The popup and the export's README now use the Ministry of Health's term for the list, since not every sensitivity is an allergy. The folder and file names are the same.
- **Inquiries are titled by their subjects**, as they appear in Maccabi Online's list.
- **No false problem for a test result without a PDF.** A result that has no PDF is no longer reported as one the export couldn't get.

Inquiries' files are named differently, so an export paused on 0.9.1 can't resume after the update, unless all it had left was the medical file: the popup asks you to discard it and start again. The [Privacy Policy](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.2/docs/privacy.md) now says that the extension keeps the day and time of your last medical file order, what Maccabi answered and whether an export has collected its file, even after you cancel an export, and what that stops. It doesn't change what's collected or where it goes, so you won't be asked to accept the policies again. The Terms of Use haven't changed.

## Install or update

You need Chrome 120 or newer.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/lmjcbhajlnbpldofejcglcdclceampjp)** and Chrome keeps it up to date, though store review can lag a day or two behind a release here.

To load this ZIP unpacked instead:

1. Download **health-records-export-for-maccabi-0.9.2.zip** from the assets below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder, the one with `manifest.json` in it. Keep that folder: Chrome loads the extension from it.

To update from an earlier version, unzip over the old folder, or load the new one and remove the old entry. Then press the reload arrow on `chrome://extensions`. An export in progress won't survive the swap: finish or stop it first.

Then [export your records](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.2/README.md#export-your-records), and [see what to ask your AI assistant](https://maccabi.ronirachmani.com/#ask). The code isn't minified, so you can read exactly what runs.

## Before you start

- **Maccabi will text you.** An export from the popup orders a fresh copy of your medical file, at most once a day, which sends an SMS and replaces the previous file on the site. It's the only change the extension makes to your account.
- **Keep the Maccabi Online tab in front** until the export finishes. Chrome pauses hidden tabs.
- **If your session ends,** log in again and press **Resume**. The files collected so far are kept.

## Privacy

- Talks only to `online.maccabi4u.co.il`. No servers, no analytics, no remote code.
- The extension's links open its website or its GitHub issue tracker in your own browser, and only when you click them. The extension sends neither one anything. The website's home page counts visits without cookies; the extension itself counts nothing.
- Never sees your password or one-time codes. It uses the session you're already logged in with.
- Apart from ordering the medical file, it only reads. Every request it makes is listed in [docs/endpoints/endpoints.json](https://github.com/RoniRachmani/health-records-export-for-maccabi/blob/v0.9.2/docs/endpoints/endpoints.json).
- **The extension sends your records nowhere, but an AI service you open them in can read them.** Check what it keeps, and for how long, before you give it your health information.
- **The ZIP isn't encrypted.** It holds your health information: keep it somewhere safe, and take care when you share it.
